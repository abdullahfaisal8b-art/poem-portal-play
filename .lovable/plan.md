# Add a puzzle game and refresh the colors

## What will change
- Add a second playable game in the Game section: a poetry word-scramble puzzle with clues, letter selection, checking, reshuffling, scoring, and new rounds.
- Let visitors switch clearly between the existing letter-guess game and the new puzzle without leaving the page.
- Replace the aged-paper colors across the site with a balanced dark-blue, light lavender-blue, and white palette while preserving the existing typography, college logo, content, and publishing tools.
- Keep both games easy to use on phones and computers, including keyboard-friendly controls and reduced-motion support.

## Technical details
- Build the puzzle as a focused React component using the existing poetry vocabulary.
- Use the project’s existing button component and semantic color tokens.
- Update global theme tokens rather than adding one-off colors to individual pages.
- Verify the Game page at desktop and mobile sizes, then check the latest site health report.
